# Money Tracker

A private, phone-first personal finance tracker. Plain HTML/CSS/JS — no build step, no dependencies.

## Features
- Monthly entries: take-home pay, bills, Amex spend
- Month-end balances: current account, cash ISA, stocks & shares ISA, JP Morgan, pension
- Net worth headline and chart
- Emergency fund progress bar with months-to-go estimate
- Surplus saved this UK tax year
- Export / import JSON backup

## Privacy
All data is stored in your browser's `localStorage`. Nothing is sent anywhere. Use **Export** to back up.

## Run
Open `index.html`, or serve the folder:

```sh
python3 -m http.server
```
